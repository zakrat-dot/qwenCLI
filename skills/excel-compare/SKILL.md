# Сравнение двух Excel-файлов (цены, остатки, наименования)

Используй этот skill, когда пользователь просит сравнить два Excel-файла:
прайсы (цены), остатки, любые значения по ключу (артикул, код, штрихкод),
или сопоставить списки номенклатуры, где ключи не совпадают, но
наименования похожи.

## Быстрый запуск (одна команда)

```
py C:\AI_PROJECTS\QWEN_LOC\scripts\compare_excel.py ^
  "<файл1>" "<файл2>" ^
  [--key Артикул] [--name Наименование] [--value "Розничная цена"] ^
  [--tol 0.001] [--fuzzy] [--fuzzy-threshold 80] [--out "результат.xlsx"]
```

- `файл1` — первый файл (обычно НОВЫЙ), `файл2` — второй (обычно СТАРЫЙ).
- `--key` — колонка-ключ в файле 1 (по умолчанию `Артикул`);
  `--key2` — если в файле 2 колонка называется иначе.
- `--value` — колонка значения. Если не задана — авто: колонка, чьё имя
  содержит «цена», иначе последняя числовая.
- `--fuzzy` — для ключей, не совпавших точно, искать похожие наименования
  (rapidfuzz `token_set_ratio`) в обе стороны.
- `--out` — путь к результату (авто: `Сравнение_<файл1>_vs_<файл2>.xlsx`
  рядом с файлом 1).

Пример (прайсы + fuzzy):

```
py C:\AI_PROJECTS\QWEN_LOC\scripts\compare_excel.py ^
  "C:\AI_PROJECTS\QWEN_LOC\Прайс_28-10-26.xlsx" "C:\AI_PROJECTS\QWEN_LOC\Прайс_002-10-26.xlsx" ^
  --fuzzy
```

Python НЕ в PATH — запускать через `py` (Python 3.11.3) или полный путь
`C:\Users\MZ3\AppData\Local\Programs\Python\Python311\python.exe`.

## Что делает скрипт (порядок)

1. **Автозаголовок** — первая строка из 15, где встречается колонка-ключ
   (в прайсах это строка 4, `header=3`; строки 0–2 — титульные).
2. **Нормализация ключа** — `12345.0 → "12345"`, пробелы убираются.
   Строки без ключа (группы/разделители) исключаются.
3. **Коллизии** — ключ, у которого в файле 2+ разных наименования
   (один артикул = разные товары). Такие ключи НЕ сравниваются,
   выносятся в лист «Коллизии» с деталями из обоих файлов.
4. **Сравнение** — inner-merge по ключу; числа — с допуском `--tol`,
   строки — на неравенство.
5. **Fuzzy** (только `--fuzzy`) — для «Только в 1» и «Только в 2»
   ищется лучшее совпадение наименования в другом файле
   (`process.extractOne`, `token_set_ratio`, порог `--fuzzy-threshold`).

## Листы результата

| Лист | Содержимое |
|---|---|
| «Различия» | Ключ, Наименование, Значение_1, Значение_2, Разница |
| «Только в 1» | ключи, которых нет во втором файле |
| «Только в 2» | ключи, которых нет в первом файле |
| «Коллизии» | детали: ключ, файл, наименование, значение |
| «Fuzzy_совпадения» | Направление (1→2 / 2→1), пары ключей/наименований, Score |

## Ключевые моменты (не исследовать заново)

- **Коллизии артикулов — реальный дефект данных**, не баг скрипта.
  В прайсах 28.10/02.10 их 6: 264901, 505186, 517042, 522854, 523677, 62136.
  Без их исключения появляются ложные «разницы цен».
- **Проверять полноту**: скрипт печатает число строк и уникальных ключей
  по каждому файлу — сверить с ожидаемым (прайсы: ~47.4k строк данных).
- **Fuzzy — для ручной проверки**, не для авто-решений: `token_set_ratio`
  даёт 100 и на разных товарах с общими токенами (напр. «Переходник 3,5мм
  шт - 6,3мм» vs «Переходник 3,5мм гн стерео - 3,5мм гн»).
- **Подозрительные значения** (цена упала в 100 раз и т.п.) — помечать
  пользователю как вероятную опечатку в прайсе, а не как факт.

## Если что-то пошло не так

- **«ОШИБКА: колонка не найдена»** — в сообщении выведен список колонок;
  передать правильное имя через `--key` / `--value`.
- **Пустой лист «Различия» при известных изменениях** — проверить
  `--value` (авто-детект мог взять другую числовую колонку) и `--tol`.
- **Много ложных fuzzy-совпадений** — поднять `--fuzzy-threshold` до 90+.
- **Медленно на 100k+ строк** — fuzzy считается только по несовпавшим
  ключам (сотни, не десятки тысяч), это нормально.

## Пример результата (прайсы 28.10 vs 02.10, 47.4k строк)

- 85 различий цен, 90 только в новом, 3 только в старом, 6 коллизии.
- Fuzzy (порог 80): 76 пар — те же товары под другими артикулами
  (напр. 650054 «Площадка монтажная FortisFlux» = 522441).
- Отдельно выгружено 23 позиции со снизившимися ценами
  (фильтр «Различия» по Разнице < 0).
