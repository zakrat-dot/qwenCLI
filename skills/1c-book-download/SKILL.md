# 1C ITS книга → Markdown (скачивание с its.1c.ru)

Используй этот skill, когда пользователь просит скачать книгу с портала 1C ITS
(`https://its.1c.ru/db/<book>`) в Markdown для Obsidian — любую книгу, не только
уже скачанные.

## Быстрый запуск (одна команда)

Мастер-скрипт делает весь пайплайн сам (warm-up → страницы → MD → картинки →
TOC → переименование → копирование в Obsidian):

```
C:\Users\MZ3\AppData\Local\Programs\Python\Python311\python.exe ^
  C:\AI_PROJECTS\QWEN_LOC\scripts\its_book.py ^
  --book <ID_книги> ^
  --output "C:\Voult\Volt\1c\Книги1сИтс\<Название книги>" ^
  --title "Полное название книги"
```

- `<ID_книги>` — часть URL после `/db/`, напр. `intgr83`.
- `--title` — человекочитаемое название для TOC (по умолчанию = ID).
- `--skip-download` — raw HTML уже скачан, пропустить скачивание страниц.
- `--skip-images` — не скачивать картинки.
- `--workdir` — рабочая папка (по умолчанию `scripts/its_pages_<book>/`).
- `--cookies` — путь к кукам (по умолчанию `scripts/its_pages/_session_cookies.json`).

Python НЕ в PATH — всегда полный путь `Python311\python.exe`.

## Что делает скрипт (порядок)

1. **Warm-up** — GET главной `https://its.1c.ru/db/<book>`. Без этого контентные
   страницы дают 401 «Доступ ограничен». Куки логина сами по себе не работают.
2. **Обнаружение страниц** — дерево оглавления `li id="toc_N"`, max pid = число
   страниц. Скачиваются страницы `1..max_pid` (непрерывно).
3. **Контент** — из `iframe#w_metadata_doc_frame` (атрибут `srcdoc` или `src`).
4. **Конвертация** — HTML→MD, понимает классы 1C ITS: `MsoNormal`,
   `command`/`interface` (инлайн-код), `bold`, `listingnazv`, `codebox`+
   `codeline[N]indent` (блок кода), `vrezkanazv`/`vrezkabody` («Подробнее»),
   `picyakor`+`img` (рисунок), `picnazv` (подпись).
5. **Картинки** — базовый URL берётся из тега `<base>` в HTML страницы
   (`/db/content/<book>/src/`). URL картинки:
   `https://its.1c.ru/db/content/<book>/src/<файл>?_=<токен>`.
   Гадать URL бесполезно — все «очевидные» паттерны дают 404.
6. **TOC.md** — оглавление, группировка по «Глава N», ссылки на md-файлы.
7. **Переименование** — `NNN.md` → `NNN. <Заголовок>.md` (номер-префикс
   сохраняет порядок и уникальность при повторяющихся заголовках).
8. **Копирование** — готовые md + `images/` + `TOC.md` в папку Obsidian.

## Ключевые моменты (не исследовать заново)

- **Warm-up обязателен.** Куки (BITRIX_SM_LOGIN, PHPSESSID) без GET главной дают
  401 на контенте. После warm-up все страницы доступны.
- **Картинки — самое трудное.** src в srcdoc относительный
  (`01_02.png?_=0000153266FEEB6F-v2`). Правильный базовый каталог — из тега
  `<base>`: `/db/content/<book>/src/`. Одинаков на всех страницах книги.
  Токен `?_=...` можно брать из src, но работает и без него.
- **Куки общие для всех книг** — один `_session_cookies.json` подходит для любой
  книги на its.1c.ru. Если все страницы 401 — куки протухли, нужен новый логин.
- **Resume** — скрипт пропускает уже скачанные страницы (файл > 500 байт) и
  картинки (> 100 байт). Можно прерывать и перезапускать.

## Если что-то пошло не так

- **401 на главной** — куки недействительны. Попросить пользователя залогиниться
  в its.1c.ru и обновить `_session_cookies.json`.
- **Нет дерева оглавления** — структура книги отличается; проверить вручную
  `workdir/_home.html`.
- **Картинки 404** — убедиться, что `discover_image_base` нашёл тег `<base>`;
  иначе скрипт использует фолбэк `/db/content/<book>/src/`.

- Финал (Obsidian): `C:\Voult\Volt\1c\Книги1сИтс\Технологии интеграции\` →
  257 md (`NNN. <Заголовок>.md`) + TOC.md + images/ (160 картинок).
