Скрипт: `C:\AI_PROJECTS\QWEN_LOC\scripts\compare_excel.py`
Скилл: `C:\Users\MZ3\.qwen\skills\excel-compare\SKILL.md`

Запуск:
```
py C:\AI_PROJECTS\QWEN_LOC\scripts\compare_excel.py <файл1> <файл2> ^
  [--key Артикул] [--key2] [--name Наименование] [--value "Розничная цена"] ^
  [--tol 0.001] [--fuzzy] [--fuzzy-threshold 80] [--out путь.xlsx]
```

Что умеет:
- Автоопределение строки заголовка (прайсы: header=3, строки 0–2 титульные)
- Нормализация ключей (float 12345.0 → "12345"), пустые строки-разделители исключаются
- Коллизии: один ключ → 2+ наименования → лист «Коллизии», из сравнения исключаются
- Числа — с допуском, строки — на неравенство
- --fuzzy: rapidfuzz token_set_ratio для несовпавших ключей (обе стороны, порог 80)

Листы: «Различия», «Только в 1», «Только в 2», «Коллизии», «Fuzzy_совпадения».

Проверено на прайсах 28.10 vs 02.10 (47.4k строк): 85 различий, 90/3 только в
одном из файлов, 6 коллизии (264901, 505186, 517042, 522854, 523677, 62136),
76 fuzzy-пар.

Важно: python не в PATH — запускать через `py`. Fuzzy — только для ручной
проверки (token_set_ratio даёт 100 и на разных товарах с общими токенами).
