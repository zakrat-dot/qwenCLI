## Задача (повторяется минимум раз в квартал/полгода)
Конвертировать экспорт диалогов ИИ в отдельные Markdown-файлы (по одному на диалог) в Obsidian-хранилище `C:\Voult\Volt\`. **Быстро, без исследования, в едином стиле.** Скрипты уже написаны — переиспользовать, не писать заново.

## Единый формат (ОБЯЗАТЕЛЬНО для ВСЕХ источников)
- Один `.md` на диалог. Имя: `{i:03d}_{sanitized_title}.md`
- Шапка: `# {title}` → пустая → блок метаданных → пустая → `---` → пустая
- Метаданные — **только строки, для которых ЕСТЬ данные**:
  - `> ID: \`{id}\`` (если есть)
  - `> Создан: {дата}` — **только если дата распознана; иначе строку НЕ вставлять**
  - `> Обновлён: {дата}` (если есть)
  - `> Модель: {модель}`
- Блоки сообщений:
  - `## 👤 Пользователь · {дата}`
  - `## 🤖 {Модель} · {дата}` (ChatGPT / DeepSeek / Gemini)
- **Дата в сообщениях — ТОЛЬКО дата `YYYY-MM-DD`, БЕЗ времени** (явное требование пользователя)
- **Сортировка: НОВЫЕ в начало (001_ = самый новый), СТАРЫЕ в конец (макс. номер = самый старый)** → `sort(..., reverse=True)`

## КРИТИЧЕСКОЕ правило перед каждым перезапуском

## Новый тип чата (напр. Anthropic Claude) — алгоритм (переиспользовать, не изобретать)
1. Найти экспорт (JSON/HTML) и структуру диалогов.
2. Определить **поле даты на сообщение** (если есть) — иначе как у Gemini (одна дата на диалог, без дат в сообщениях).
3. Написать/адаптировать скрипт **по ЭТОМУ же формату**: шапка, блоки `## 👤/## 🤖`, даты-только-дата, сортировка новые-в-начало.
4. Удалить старые `.md` в папке вывода → запустить → проверить: `001_` = самый новый, макс. номер = самый старый; даты в сообщениях на месте.
5. Отчитаться на русском.

## Постоянные правила
- Отвечать **ТОЛЬКО на русском**.
- **Не циклиться** — фиксить и идти дальше линейно.
- Если даты нет — строку «Создан:» **НЕ вставлять**.
- Вложения (картинки/файлы) — копировать в `attachments/` и линковать через Obsidian `![[...]]` / `[[...]]`.
