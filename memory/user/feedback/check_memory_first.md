**Правило:** ПЕРЕД ЛЮБОЙ работой (особенно исследованием структуры БД/метаданных) сначала прочитать память проекта: папку `memory/` текущего проекта + `MEMORY.md` в `C:\Users\MZ3\.qwen\projects\<проект>\memory\`. Только потом — DuckDB (`meta_schema.duckdb` / `semantic_core.duckdb` в `C:\AI_PROJECTS\Base_DuckDb\data\`) как основной источник метаданных 1С. Текстовые словари (`СтруктураБУХ.txt` и пр.) — ПОСЛЕДНЯЯ очередь. Никогда не гадать имена таблиц, колонок, атрибутов.

**Why:** 2026-10-05 пользователь трижды потребовал это зафиксировать («ТЫ ВСЕГДА ПРЕЖДЕ ИЩЕШЬ В ПАМЯТИ! ... припиши это в системном промте, запомни заруби это УЖЕ НАВСЕГДА»). Причина: из-за игнорирования памяти и DuckDB были выданы выдуманные имена доп. реквизитов («Ставка НДС», «Тип плательщика НДС»); реальные — «КоличествоЧасов», «Релевантность» (найдены в `_Chrc1090X1`).

**How to apply:** В начале любой задачи, где нужны структуры 1С/таблицы/имена полей: (1) `MEMORY.md` + файлы памяти проекта, (2) DuckDB meta_schema/semantic_core, (3) текстовые словари — только как fallback. Это требование действует для всех проектов пользователя.
