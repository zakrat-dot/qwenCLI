**Правило:** При ЛЮБОМ упоминании DashBord / Дашборд — ПЕРЕД любыми действиями прочитать память минимум из ДВУХ мест:

1. **Глобальная память** `~/.qwen/memories/` + `~/.qwen/projects/*/memory/MEMORY.md` (всегда загружается автоматически)
2. **Папка текущего проекта** — если Qwen запущен в папке DashBord или связанной, проверить есть ли там `.qwen/memory/`, `MEMORY.md`, локальные файлы памяти

Потом уже: DuckDB meta_schema → текстовые словари (fallback). Никогда не начинать исследование структуры БД заново.

**Why:** Пользователь прямо потребовал (2026-10-07): "запомни и пропиши это в памяти, чтобы эти данные про сайт были тоже записаны... при запуске из любой папки ты всегда должен знать что память может как минимум в двух местах". Память проекта разбросана между глобальной ~/.qwen/ и локальной рабочей директорией.

**How to apply:** Как только пользователь упоминает DashBord / Дашборд: (1) прочитать все MEMORY.md индексы из доступных мест, (2) загрузить ключевые файлы памяти проекта, (3) DuckDB при необходимости, (4) текстовые словари — только как fallback.
