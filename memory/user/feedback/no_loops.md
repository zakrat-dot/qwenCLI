---
name: Не циклиться — делать работу без повторений
description: Пользователь требует выполнять задачи линейно, без зацикливания и повторяющихся попыток
type: feedback
---

**Правило:** При выполнении задач не зацикливаться на одном подходе. Если что-то не работает с первого раза — исправить ошибку и продолжить дальше, а не повторять те же шаги или возвращаться к уже пройденным этапам. Делать работу линейно без возвратов назад.

**Why:** Пользователь явно сказал «не циклись!!» при работе над скриптами исследования регистра бухгалтерии. Повторяющиеся попытки с одними и теми же ошибками раздражают пользователя.

**How to apply:** При выполнении многошаговых задач (скрипты, исследование БД) — если шаг упал с ошибкой: 1) исправить конкретную ошибку, 2) продолжить со следующего шага, не начиная заново. Не возвращаться к уже выполненным этапам без причины.
