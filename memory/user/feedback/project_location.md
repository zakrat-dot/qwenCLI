---
name: Project save location
description: All new projects must be saved to C:\AI_PROJECTS\QWEN_LOC in separate subfolders
type: feedback
---

Все новые проекты должны сохраняться в `C:\AI_PROJECTS\QWEN_LOC` в отдельную папку для каждого проекта.

**Why:** Пользователь хочет централизованное место для хранения проектов Qwen Code на локальной машине.

**How to apply:** При создании любого нового проекта использовать `C:\AI_PROJECTS\QWEN_LOC\имя-проекта\` как базовую директорию.
