---
name: Скрипты в отдельной папке scripts/
description: Все Python-скрипты для проектов должны сохраняться в папку scripts/
type: feedback
---

Все скрипты для проектов должны сохраняться в отдельную папку `scripts/` в корне проекта.

**Why:** Пользователь хочет чистую структуру проекта, чтобы скрипты не смешивались с основными файлами.

**How to apply:** При создании любого нового скрипта (.py, .bat, .sh и т.д.) помещать его в `scripts/` папку проекта. Если папки нет — создать.
