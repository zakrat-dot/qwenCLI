## Основная таблица контрагентов

В базе `BP_MAIN_COPY` контрагенты хранятся в `_Reference119` (не `_Reference77` — она пустая).

- **924 записи**, 47 колонок
- `_Fld119` — GUID элемента
- `_Fld120` — GUID родителя (NULL = корень группы)
- `_Fld121` — код, `_Fld122` — название
- `_Fld123` — INN, `_Fld124` — KPP, `_Fld125` — ОГРН
- `_Fld126` — флаг удаления (deletedMark), `_Fld127` — флаг пометки удаления
- Фильтр: `deletedMark = 0 AND markForDelete = 0`

## Иерархия групп

Группы — это элементы того же справочника. Родитель указывается в `_Fld120`. Корневые группы имеют `_Fld120 IS NULL`. Для разрешения названий групп нужно делать JOIN на ту же таблицу по `_Fld120 = _Fld119`.

### Телефоны в VT3042

- `_Fld3042` — GUID контрагента
- `_Fld3046` — представление телефона (строка с форматированием)
- `_Fld3052` — номер телефона (сырой)
- Фильтр: `_Fld3046 LIKE '%+%'` или `_Fld3052 LIKE '%+%'` — строки с телефонами
- Остальные строки VT3042 — адреса

### Дополнительные реквизиты в VT3058

- `_Fld3058` — GUID контрагента
- `_Fld3060` — GUID типа дополнительного реквизита
- `_Fld3062` — значение (NVARCHAR)
- `_Fld3064` — значение (NUMERIC)
- `_Fld3066` — значение (DATE)

Типы реквизитов:
- `acb2a8a159238df711efbe07b832ee6f` — Ставка НДС (38 вхождений)
- `acaba8a159238df711ef020acfddd5fb` — Тип плательщика НДС (8 вхождений)

## Пример запроса

```python
import pymssql
from config import DB_CONFIG

conn = pymssql.connect(**DB_CONFIG)
cursor = conn.cursor()

# Все контрагенты
cursor.execute("""
    SELECT _Fld119, _Fld120, _Fld121, _Fld122, _Fld123, _Fld124, _Fld125
    FROM _Reference119
    WHERE _Fld126 = 0 AND _Fld127 = 0
""")

# Телефоны
cursor.execute("""
    SELECT _Fld3058, _Fld3046, _Fld3052
    FROM _Reference119_VT3042
    WHERE _Fld3046 LIKE '%+%' OR _Fld3052 LIKE '%+%'
""")

# Доп. реквизиты
cursor.execute("""
    SELECT _Fld3058, _Fld3060, _Fld3062, _Fld3064, _Fld3066
    FROM _Reference119_VT3058
""")
```

## Why

Пользователь просил сохранить этот опыт, чтобы не повторять исследование таблиц при будущих доработках дашборда.

## How to apply

При любых запросах на добавление данных по контрагентам в дашборд — использовать эти таблицы и структуру, не исследовать заново.
