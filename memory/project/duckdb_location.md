DuckDB база метаданных 1С находится в:

**C:\AI_PROJECTS\Base_DuckDb\data**

Это основная база для просмотра структуры метаданных 1С (справочники, регистры, документы, поля). Используется для:
- Определения физической структуры таблиц MSSQL (_AccRg1112, _Document*, _Reference*)
- Понимания типов колонок, связей, имён полей
- Создания правильных SQL-запросов для дашборда

Рядом в `C:\AI_PROJECTS\Base_DuckDb\src\` лежат текстовые/HTML словари (СтруктураБУХ.txt, структураБУХ.html, 1c_final_dictionary.csv, db_schema.json) — дублирующая информация из той же базы.

**Как использовать:** когда нужно понять структуру регистра/документа/справочника 1С — смотреть DuckDB базу или текстовые словари в src/. Никогда не гадать названия колонок.
