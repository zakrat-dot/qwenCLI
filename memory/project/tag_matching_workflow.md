Повторяемая задача: сопоставление тегов 1С между шаблоном договора (doc1) и новым документом (doc2).

**Шаги:**
1. Извлечь все теги `{v8 ...}` и `{/v8 ...}` из `ДоговорВорде.docx` (python-docx + regex)
2. Прочитать `Трудовой договор_исправленый.doc` (или конвертированный `.docx`) — найти жёлтую подсветку (`run.font.highlight_color == "YELLOW (7)"`)
3. Конвертировать оба документа в Markdown для сохранения номеров пунктов (python-docx стирает динамические номера 4.1, 4.1.1)
4. Сопоставить теги с местами в doc2 по смыслу
5. Выгрузить в Excel (`теги_сопоставление.xlsx`) с колонками: №, Номер пункта, Тип (Раздел/Подпункт/Секция), Название, Имя тега, Статус (✅/❌), Смысловая нагрузка
6. Все строки: разделы, подпункты, строки с тегами, жёлтые места без тегов — всё в одной таблице для поиска
7. Нумерация: Шапка → 1, 2, 3... 10; подпункты 1.1, 1.2...; вложенные 4.1.1, 4.1.2

**Ключевые скрипты:** `scripts/create_final_excel_with_subsections.py`, `scripts/convert_to_markdown.py`, `scripts/analyze_doc2.py`

**Why:** Пользователь работает с шаблонами договоров 1С и регулярно сравнивает старые шаблоны с новыми версиями.

**How to apply:** При запросе "тоже самое для других файлов" — повторить те же шаги с новыми входными файлами.
