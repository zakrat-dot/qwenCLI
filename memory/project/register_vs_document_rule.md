## Правило: Регистр ≠ Документ при поиске контрагентов

При работе с данными бухгалтерии 1С критически важно различать **два источника данных**: регистр Хозрасчетный и таблицы документов. Контрагент хранится по-разному в каждом из них.

### В регистре _AccRg1112 (Хозрасчетный) — композитное субконто

Контрагент на кредитной стороне проводки хранится через **композитный разрез Ct1**:
```sql
-- Правильно: контрагент через субконто Ct1
LEFT JOIN _Reference119 c ON d._ValueCt1_RRRef = c._IDRRef

WHERE d._AccountDtRRef = {idrref_51}          -- Дт счёт 51
  AND d._AccountCtRRef IN ({list_62})         -- Кт группа 62.xx
```

**Никогда не ищите `_FldXXXXX_RRRef` в регистре!** Такого поля нет. В хозрасчетном регистре контрагент — это субконто, а не прямое поле.

### В таблице документа (например _Document512) — прямое поле

Документы хранят контрагента как обычное ссылочное поле:
```sql
-- Документ СписаниеСРасчетногоСчета (_Document512)
LEFT JOIN _Reference119 k ON d._Fld15680_RRRef = k._IDRRef   -- прямое поле!
WHERE d._Posted = 1 AND d._Marked = 0
```

### Почему это важно?

Если вы ищете контрагента в регистре через `_FldXXXXX`, запрос вернёт ошибку «колонка не существует». Если используете документ вместо регистра — получите неполные данные (не все документы имеют такие поля, да и агрегация по проводкам только через регистр).

### Как определить источник?

- **Агрегация оборотов/сальдо** → всегда `_AccRg1112` + субконто Ct1
- **Конкретный тип документа с уникальными полями** → таблица `_Document{N}` + прямое поле
- **Сумма проводки в регистре** → колонка `_Fld1116`, не путать с валютной суммой `_Fld1117`
