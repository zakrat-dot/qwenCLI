name: Workflow сравнения и слияния Excel файлов по ключам
description: Обобщённый процесс сопоставления двух Excel файлов по одному или составному ключу с поиском несовпадений
type: feedback
---

При запросе «сравни», «добавь поля», «соедини файлы» — применять общий workflow с параметризованными ключами.

**Правила:**

1. **Ключ соединения** — уточнить у пользователя или определить автоматически:
   - **Одно поле** — например `Код`, `Номенклатура`, `UID`
   - **Составной ключ** — логическое И двух и более полей: `поле1_файла1 = поле1_файла2 И поле2_файла1 = поле2_файла2`
   - Поля в двух файлах могут называться по-разному — сопоставить по смыслу

2. **Очистка перед сравнением** — все ключевые поля: `.astype(str).str.strip()`

3. **LEFT JOIN** — из основного файла (того, который пользователь назвал «вторым» или из которого «берём данные»). Все строки основного + подтянутые поля из второго

4. **Порядок строк** — как в файле-источнике (первом, который задаёт порядок)

5. **Проверка несовпадений** — для текстовых полей:
   - Если одно значение содержится в другом (`in`) → **частичное** совпадение (лишние единицы, суффиксы)
   - Если ни одно не содержится в другом → **полное** несовпадение (разные данные под одним ключом)
   - Полные несовпадения → отдельный выходной файл

6. **Выходные файлы:**
   - Основной — слитые данные с правильным порядком
   - `несовпадения_полные.xlsx` — только критические расхождения
   - Имя файла уточнить у пользователя или дать логичное по содержимому

**Примеры ключей:**
- По одному полю: `Код` → `Код`
- По составному: `Номенклатура + Организация` → `Наименование + Орг`
- По трём полям: `Код И Период И Организация` → `Code И Date И Org`

**Why:** Пользователь регулярно сравнивает и сливает Excel-файлы с разными структурами. Ключи могут быть любыми — одно поле, два поля, составной ключ. Файлы меняются от задачи к задаче.

**How to apply:** При коротком запросе «сравни по колонке X», «добавь поля из файла Y», «соедини по ключу» — применять workflow. Если ключ неочевиден — задать один вопрос, а не переспрашивать всё остальное.
