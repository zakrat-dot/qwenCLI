Все страницы по банку (поступления, расходы/оплаты) в дашборде DashBord обязаны показывать: **Организация, Контрагент, Сумма**. Плюс для банка — **дата последнего** и **количество** (как в сводке по контрагентам). В выборке — **только проведённые документы** (`_Posted = 1`).

**Why:** Пользователь прямо указал это как обязательный вид для проекта и попросил запомнить. Забыл показать организацию/контрагента/сумму при первой итерации — попросил добавить.

**How to apply:** При создании любой новой страницы/запроса по банку (поступления, списания, оплаты) всегда включать в SELECT и в UI: организацию, контрагента, сумму, дату последнего, количество. Фильтровать `_Posted = 1` (и `_Marked = 0`). Не делать выборку без этих полей.
